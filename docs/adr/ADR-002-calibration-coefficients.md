# ADR-002 — Calibração explícita, sem precisão inventada

Status: aceito.

Nenhum coeficiente quantitativo é fornecido no seed. Fixtures matemáticas existem somente em testes; fixtures de integração pertencem a organizações efêmeras e são eliminadas ao final.

Recomendações exigem VERIFIED, evidência declarada, aprovador, data, base e contexto exatos. Dados DEMO e coeficientes ambíguos não liberam doses. Alteração de VERIFIED retorna a DRAFT, gera nova versão e exige revalidação independente. Snapshots preservam a informação realmente usada na adição.

Não se interpreta limite mínimo como autorização para aumentar dose: resultados fora da faixa bloqueiam a recomendação.
